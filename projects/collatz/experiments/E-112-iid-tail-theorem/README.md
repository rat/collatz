# E-112: hypotheses of the iid martingale-tail theorem

This experiment checks the algebraic part of the application of the additive
branching-random-walk tail theorem to paper 01.

For the iid model, put `theta = alpha_minus(q)` and

```text
psi(s) = log rho_ann(theta*s),
rho_ann(t) = q^(t-1)/(2^t-1).
```

The script verifies for representative odd `q` that `psi(1)=0`, that the
second zero is `kappa=alpha_plus/alpha_minus`, and that `psi'(1)<0`. The
remaining moment hypotheses are analytic: the branch weights form geometric
ladders and there are finitely many residue types, so every weighted sum with
a polynomial factor in the displacement is bounded. The closed additive group
generated by the one-step displacements contains both `theta*log(2)` and
`theta*log(q)`. It is dense because `log(q)/log(2)` is irrational for odd
`q>1`, by unique factorisation. This supplies the non-lattice condition used
by the renewal theorem.

Run `python3 check_assumptions.py`.

This verifies only the iid model. It does not transfer the result to a fixed
arithmetic reverse tree.
